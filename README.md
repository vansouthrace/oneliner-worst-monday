One funny line, at most 140 characters, about an AI agent's worst Monday — my entry for the [Worst Monday One-Liners](https://make.fun/bounty/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28) bounty on make.fun. Winner takes all $3.

## Run

```sh
node main.ts
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), refusing to write if the line is outside the 1–140 character limit.
